# Incubyte Assignment – Full Stack Application

This project is a full-stack web application built as part of the **Incubyte assignment**.  
It follows a **clean separation of concerns** with independent frontend and backend layers managed using Git best practices.

---

## 📌 Tech Stack

### Frontend
- React.js
- JavaScript
- CSS
- Context API (for authentication state)

### Backend
- Node.js
- Express.js
- REST APIs

### Database
- SQL (schema provided)

### Version Control
- Git & GitHub (branch-based workflow)
